## Домашняя работа №1

Домашняя работа №1 состоит из двух мини-задач.

### Мини-задача 1: Zipf, предобработка и интенты

Файл: `1st/первая мини-задача/homework_task1.py`

Что делает скрипт:

1. Загружает фрагмент «Белых ночей» и строит анализ по закону Ципфа.
2. Считает длинный хвост словаря: hapax и слова с частотой `<= 3`.
3. Сравнивает варианты предобработки:
   - raw,
   - lowercase,
   - замена `ё -> е`,
   - удаление коротких слов,
   - лемматизация (`pymorphy3`, если установлен).
4. Определяет интенты через `spaCy Matcher`:
   - базовые (`greeting`, `goodbye`, `ask_weather`, `ask_time`),
   - добавленные (`ask_recommendation`, `express_gratitude`).

Результат выполнения:

- таблицы частот и сравнения словарей;
- графики (Zipf + размер словаря по шагам предобработки);
- распознанные интенты для тестовых фраз.

### Мини-задача 2: токены, стеммы, леммы, NER, POS и DEP

Файл: `1st/вторая мини-задача/homework_task2.py`

Что делает скрипт:

1. Загружает русский художественный текст.
2. Сравнивает частоты и словари для:
   - токенов,
   - стемм (`nltk` SnowballStemmer),
   - лемм (`pymorphy3`).
3. Считает долю длинного хвоста (`f <= 3`) для каждого представления.
4. Для нескольких предложений показывает:
   - POS,
   - DEP,
   - NER из `spaCy`,
   - сравнение лемм `spaCy` и `pymorphy3`.
5. Извлекает персонажей (NER `PER`) и считает частоты упоминаний.
6. Ищет предложения с приветствиями двумя способами:
   - через `regex`,
   - через `spaCy Matcher`.

Результат выполнения:

- сравнительные таблицы;
- графики по словарям и хвосту;
- список персонажей и найденные приветствия.

## Домашняя работа №2

Основной файл: `2nd/МПИ_25_1_2_Исмаилова_Наргиз_Domain_Shift.ipynb`

Подробное текстовое описание: `2nd/README`

Работа состоит из двух частей.

### Часть A: Domain Shift и распределения

1. Используется датасет `data-silence/rus_news_classifier`.
2. Сравниваются два домена: `politics` и `sports`.
3. Считаются log-odds токены в обе стороны.
4. Анализируются распределения:
   - длины документов,
   - Zipf-кривые.
5. Проверяется влияние предобработки: стоп-слова и лемматизация.

### Часть B: Authorship Attribution (Naive Bayes)

1. Поэтический корпус делится на чанки.
2. Обучается `MultinomialNB` для определения автора.
3. Оцениваются `accuracy`, `macro F1` и `confusion matrix`.
4. Анализируются важные токены по разнице лог-вероятностей.
5. Сравниваются варианты с лемматизацией и n-граммами.
6. Отдельно проверяется domain shift: длинные тексты -> короткие.

## Домашняя работа №3

Основной файл: `3rd/МПИ_25_1_2_Исмаилова_Наргиз_word2vec_retrieval.ipynb`

Датасет: книга Анара «Шестой этаж пятиэтажного дома» в формате FB2.

Работа состоит из трёх частей.

### Часть 1: Готовые русские эмбеддинги

1. Загружается предобученная модель `word2vec-ruscorpora-300` из `gensim-data`.
2. Анализируется формат ключей `лемма_POS`.
3. Для набора слов из разных доменов выводятся ближайшие соседи.
4. Делается качественный анализ семантической близости.

### Часть 2: Обучение Word2Vec на своём датасете

1. Парсится книга Анара из FB2.
2. Выполняется токенизация: lowercase + кириллические слова длиной > 1.
3. Обучается Skip-gram модель.
4. Выводятся ближайшие соседи для слов и имён персонажей.
5. Сравнивается своя модель с готовой.

### Часть 3: Построение retrieval-индекса

1. Текст разбивается на фрагменты с перекрытием.
2. Строятся эмбеддинги документов двумя способами:
   - Mean Word2Vec,
   - TF-IDF Weighted Word2Vec.
3. Создаётся FAISS-индекс.
4. Тестируется поиск по нескольким запросам.
5. Делается вывод о качестве retrieval.

## Домашняя работа №4

Основной файл: `4th/МПИ_25_1_2_Исмаилова_Наргиз_tokenizers_tensors.ipynb`

Опорный семинарский ноутбук: `4th/tokenizers_tensors_attention_seminar.ipynb`

Работа посвящена токенайзерам, размерам тензоров и базовому анализу attention в моделях из `transformers`.

### Содержание мини-упражнений

1. Сравнивается дополнительный токенайзер `google/byt5-small` с уже рассмотренными `BERT`, `GPT-2`, `mT5` и `XLM-R` на русском тексте и на коде.
2. Для `B = 2`, `T = 7`, `d_model = 768`, `h = 12` вручную выписываются размеры:
   - `Q`, `K`, `V`: `(2, 12, 7, 64)`,
   - `QK^T`: `(2, 12, 7, 7)`.
3. Разбирается ещё одна модель из `transformers`: `google/bigbird-roberta-base`.
   - число слоёв: `12`,
   - число голов: `12`,
   - скрытая размерность: `768`,
   - особенность attention: `block_sparse` вместо полного self-attention.
4. Находится конкретный параметр, соответствующий `W_K`, на примере `DistilBERT`:
   - `transformer.layer.0.attention.k_lin.weight`.
5. Выбирается attention-head с заметным паттерном в `DistilBERT`:
   - `layer = 3`, `head = 4`,
   - интерпретация: голова локального левого контекста и границ фраз.

### Что есть в ноутбуке

- короткие текстовые выводы по каждому пункту;
- код для воспроизведения результатов;
- визуализация attention для выбранной головы;
- отдельная ячейка с фиксом для `pandas/transformers`, если ноутбук запускается в Colab/Kaggle и импорт ломается на окружении.
